ambiente de desenvolvimento local.

  dependências do projeto.
- [Pipeline local](local-pipeline.md) — `scripts\check.cmd` e o que ele

- [Testes de integração](integration-tests.md) — suíte PostgreSQL real
  isolada.
- [Testes E2E](e2e-tests.md) — suíte fim a fim reproduzível.
- [Convenções de API](api-conventions.md) — regras para novos endpoints.

Para rodar o projeto localmente (não só os testes), veja
